# WeekProcessor

WeekProcessorはGameSimulationから呼ばれる内部の週次プロセッサー。外部アセンブリへ公開しない。

- 割当とProductStateを受け取り、更新前のスキル・疲労・負債で社員ごとの進捗を計算する。割当辞書は変更しない。
- nullの引数・社員別割当、負の勤務時間を確定前に拒否する。プロセッサー自身は継続状態を保持しない。
- Prepareは各タスクへ進捗変更の準備を依頼し、その完了判定に基づいて完了効果を合算する。ProductStateに合算後の変更を準備させる。
- 社員一覧が指定されていれば、無割当を含む各社員の週末処理も準備する。勤務時間と疲労の変更は社員自身が所有する。
- タスク順・社員順を指定すると、結果はその登録順に並ぶ。割当辞書への追加・取消・再登録順には依存しない。
- PreparedWeek.Commitは全対象の状態を先に検証し、準備時から変化していなければ同じ計算結果を各所有者へ一度だけ反映する。週報で計算式・上限制御・完了判定を再実装しない。
- 上限を超えた進捗は破棄する。勤務時間の返却や他タスクへの再配分は行わない。
- 週番号・履歴・割当のクリアはGameSimulationが担当する。単一スレッドで使用する。

GameSimulationはPrepareとCommitの間にWeekResultを確保する。入力検証や計算・レポート構築の失敗で一部の状態だけを更新しない。内部のProcessは従来どおりタスクとプロダクトのみを処理する呼出しで、社員の勤務時間・疲労を更新しない。

補正式・係数・週次順序は[ProductHealth](./ProductHealth.md)、変更結果の契約は[PlanningAndReports](./PlanningAndReports.md)を参照。表示用の丸めは加えない。
