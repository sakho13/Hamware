# WeekProcessor

WeekProcessor は週送り時の処理を担当します。

- タスク→社員→実勤務工数の割当を読み取る。割当辞書と社員の勤務時間・疲労は変更しない。
- 割当と`ProductState`を必須引数として受け取り、nullは進捗を変更する前に拒否する。プロセッサー自身は継続状態を保持しない。
- `TaskSkillProfiles`からタスク種別の対応表を取得し、`ProductivityCalculator`で社員ごとの進捗を計算する。
- 週送り時点のスキルと更新前の疲労を参照する。さらに`TaskProductProfiles`で選択した対象にのみ開始時の負債倍率を掛け、社員別の進捗をタスク単位で合算して`ApplyProgress`へ渡す。計算はdecimalの精度で行い、表示用などの明示的な桁丸めは追加しない。
- 未完了から完了になったタスクの必要進捗工数とプロファイルから増減を集計し、全タスク処理後に`ProductState`へ一度だけ渡す。状態自身が合計増減を上下限内へ制限する。既完了タスクへの再適用は行わない。
- 当週の進捗には全タスクで同じ負債値を使い、当週の完了効果が列挙順で他タスクへ影響しないようにする。係数と具体例は[ProductHealth](./ProductHealth.md)を参照。
- 完了を超える進捗の上限処理はタスク自身が担当する。勤務時間の返却や他タスクへの再配分は行わない。
- 全タスクの処理後に`GameSimulation`が各社員の週末更新を呼ぶ。社員が疲労更新と利用可能工数のリセットを行い、シミュレーションが割当のクリアと週番号の更新を行う。
