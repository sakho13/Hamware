# WeekProcessor

WeekProcessor はGameSimulationから呼ばれるシミュレーション内部用の週次プロセッサーです。外部アセンブリへ公開しません。

- タスク→社員→実勤務工数の割当を読み取る。割当辞書と社員の勤務時間・疲労は変更しない。
- 割当と`ProductState`を必須引数として受け取る。引数のnull、割当内のnull、負の勤務時間は状態を変更する前に拒否する。プロセッサー自身は継続状態を保持しない。
- `TaskSkillProfiles`からタスク種別の対応表を取得し、`ProductivityCalculator`で社員ごとの進捗を計算する。
- 最初に全割当の進捗と完了効果を計算し、結果を一時保持する。この段階ではタスクとプロダクトを変更しない。後続の割当が不正な場合にも、先行タスクの進捗が途中まで確定することを防ぐ。
- 全件の検証・計算が成功してから、内部用の`ApplyProgress`と`ProductState`の更新操作で結果を反映する。進捗から残工数との比較で新規完了を判定し、完了効果の計算も反映前に済ませる。
- 補正式・係数・週次順序・状態変化の反映時期は[ProductHealth](./ProductHealth.md)を参照。表示用などの明示的な桁丸めは追加しない。
- 完了を超える進捗の上限処理はタスク自身が担当する。勤務時間の返却や他タスクへの再配分は行わない。
- 社員の週末更新とシミュレーションの週番号管理は担当しない。
