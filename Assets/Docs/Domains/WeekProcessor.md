# WeekProcessor

WeekProcessor は週送り時の処理を担当します。

- タスク→社員→実勤務工数の割当を読み取る。割当辞書と社員の勤務時間は変更しない。
- `TaskSkillProfiles`からタスク種別の対応表を取得し、`ProductivityCalculator`で社員ごとの進捗を計算する。
- 週送り時点のスキルを参照し、補正後の進捗をタスク単位で合算して`ApplyProgress`へ渡す。計算途中や週末に端数を丸めない。
- 完了を超える進捗の上限処理はタスク自身が担当する。勤務時間の返却や他タスクへの再配分は行わない。
- 割当のクリア、週番号の更新、利用可能工数のリセットは`GameSimulation`が担当する。
