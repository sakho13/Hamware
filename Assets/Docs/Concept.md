# Concept - Hamware

Hamware は、スタートアップのソフトウェア開発現場を題材にしたシミュレーションゲームです。

かわいいハムスターの社員たちとともに、限られた工数を使ってタスクを進め、仕様変更、問い合わせ、障害、技術的負債などに対応しながらプロダクトを成長させる。

会社経営そのものよりも、**「限られたチームでソフトウェア開発をどう前に進めるか」**をゲームの中心に据えている。

明確なクリア条件を設けるより、プレイヤー自身が会社やプロダクトの方向性を決めるサンドボックス型のゲームです。。
